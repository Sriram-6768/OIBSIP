# Task 2 - Unemployment Analysis with Python

## Objective
Analyze unemployment data in India to identify regional and temporal trends, with a focus on the impact of COVID-19.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data loading and cleaning
- Missing-value and data-type analysis
- Region-wise unemployment analysis
- Monthly unemployment trends
- Top 10 regions by unemployment
- Labour participation analysis
- Correlation analysis
- COVID-19 related unemployment analysis

## Files
- Unemployment_Analysis.ipynb
- Unemployment in India.csv
