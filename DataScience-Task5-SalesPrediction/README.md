# Task 5 - Sales Prediction Using Python

## Objective
Build a regression model to predict product sales based on advertising expenditure across TV, Radio, and Newspaper.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Analysis Performed
- Data loading and exploratory data analysis
- Missing-value checking
- Descriptive statistics
- Feature relationship visualizations
- Correlation analysis
- Train/test split
- Linear Regression model
- Additional regression model
- Model evaluation using MAE, RMSE, and R²
- Analysis of advertising-channel impact on sales
